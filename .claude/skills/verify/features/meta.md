# Meta

Browsers, crawlers and share cards get icons, a share image, a manifest, robots and a sitemap.

## Sub-features

- icon.svg: the mark, adapting to dark mode; favicon.ico: 16, 32 and 48 px PNGs generated by `tools/favicon.ts`.
- apple-icon: 180 px PNG; opengraph-image: 1200 by 630 PNG with live store numbers.
- manifest, robots (allow all, sitemap link), sitemap (static pages, docs, every topic, claim and run).
- badges (`web/lib/badges.ts`, `web/app/badge/[name]/route.ts`, force-static): `/badge/claims.svg`, `lab.svg`, `evaluator.svg`, `sealed.svg`, each one number from the edition the build serves (claims published; the newest lab run per release, passed of run and red when one failed or a release did not verify; recent test claims the evaluator caught, red when it missed one or paused; the newest snapshot and its block). The README shows them, each linked to the page that proves it. A monospace face, so widths need no font metrics.
- security.txt (RFC 9116, `web/app/.well-known/security.txt/route.ts`): Contact is GitHub's private vulnerability reporting for the repository, Policy is SECURITY.md, Expires is 180 days after the edition the build serves, so every deploy renews it.

## How to reach it

- `<link rel="icon">`, `<link rel="apple-touch-icon">`, `<meta property="og:image">` in every page head; `/robots.txt`, `/sitemap.xml`, `/manifest.webmanifest`.

## How to check it

Static: `pnpm lint`.

Runtime:

```sh
for p in /icon.svg /favicon.ico /apple-icon /opengraph-image /manifest.webmanifest /robots.txt /sitemap.xml; do printf '%s ' $p; curl -s -o /dev/null -w '%{http_code} %{content_type}\n' localhost:3721$p; done
curl -s localhost:3721/sitemap.xml | grep -c '<loc>'
```

`for n in claims lab evaluator sealed nope; do curl -s -o /dev/null -w "$n %{http_code} %{content_type}\n" localhost:3721/badge/$n.svg; done` gives 200 image/svg+xml for the four and 404 for `nope`; `curl -s localhost:3721/badge/lab.svg | grep -o '<title>[^<]*'` reads like "release lab: 148 of 148 passed", matching the lab table on `/security`.

`curl -s localhost:3721/.well-known/security.txt` answers 200 text/plain with Contact, Expires (a future date, 180 days after `edition.generated.time` in `curl -s localhost:3721/api/v1`), Policy, Preferred-Languages and Canonical lines.

Proves it when: each answers 200 with image/svg+xml, image/x-icon (or vnd.microsoft.icon), image/png, image/png, application/manifest+json, text/plain, application/xml; the sitemap has 11 fixed pages plus one per topic, claim and run (36 with 1 topic, 23 claims, 1 run).

## Gotchas

- `/apple-icon` and `/opengraph-image` URLs carry a hash query in the head; the bare paths also answer.
